# PDFRune

PDFRune contains bounded operations for existing PDF documents. It is the
post-generation companion to PaperRune, but neither module imports the other.
Applications compose them at their own trusted boundary.

## Packages

- `sign` adds and verifies detached CMS/PAdES signatures.
- `importpdf` parses the supported PDF subset. Cross-reference streams, object
  streams, and the standard security handler (RC4, AES-128, AES-256) are first
  normalized into an equivalent classic-xref, unencrypted file; encrypted
  sources open with `ImportOptions.Password` (user or owner password).
- `inspect` reports page structure, dimensions, streams, and text.
- `pdfcdr` reconstructs the supported subset while removing interactive and
  non-rendering document structures.
- `characterize` produces deterministic evidence from committed PDF bytes.
- `pdfverify` binds structural, raster, tag, and compliance evidence to exact
  PDF bytes.

Every package accepts an existing PDF as input. PDF generation and Paper
authoring deliberately remain outside this module.

## Server composition

Generate with PaperRune first, then pass the resulting bytes to PDFRune from
the application server:

```go
var generated bytes.Buffer
if err := doc.Output(&generated); err != nil {
	return err
}

signed, err := sign.AppendBytesContext(ctx, generated.Bytes(), options)
```

For production signing, provide an HSM, KMS, PKCS#11, operating-system-backed,
or other managed `crypto.Signer`. Mounted PEM credentials are supported for
explicit operator and container-secret workflows.

## Scope

The parser is intentionally narrow and bounded. It is not a general-purpose
PDF renderer and it does not make untrusted PDFs safe for arbitrary downstream
viewers.
